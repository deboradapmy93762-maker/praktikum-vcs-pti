# praktikum-vcs-pti
Latihan Version Control System mahasiswa PTI
# Deskripsi proyek 
Repositori ini dibuat untuk memenuhi tugas Praktikum 1 mata kuliah Administrasi Digital tentang Version Control System. Yang bertujuan untuk memahami penggunaan GitHub, mempelajari cara membuat repositori, memahami penggunaan README.md. dan mempelajari cara menyimpan perubahan menggunakan commit.
